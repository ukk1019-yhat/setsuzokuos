## 1. Purpose

This Acceptable Use Policy defines acceptable and prohibited behavior when accessing or utilizing Setsuzoku OS. It applies to all account owners, managers, producers, employees, client portal users, and API consumers.

---

## 2. Prohibited Activities

You agree not to use Setsuzoku OS to:
1. **Infringe Intellectual Property:** Upload, distribute, or store materials that violate copyrights, trademarks, trade secrets, patents, or moral rights of any third party.
2. **Distribute Malicious Code:** Transmit viruses, worms, Trojan horses, ransomware, web shells, or scripts designed to disrupt or damage computer systems.
3. **Engage in Unauthorized Access & Exploitation:**
   - Probe, scan, or test the vulnerability of Setsuzoku systems or bypass authentication and tenant isolation checks.
   - Execute Insecure Direct Object Reference (IDOR) attacks or tamper with organization identifiers.
   - Forbid web scraping or automated extraction of platform data without express written permission.
4. **Circumvent Billing or Security Controls:** Forge webhook signatures, replay payment notifications, or manipulate financial line-item calculations.
5. **Abuse System Resources:** Execute denial-of-service (DoS) attempts, flood API endpoints, or store non-work-related multi-terabyte archives unrelated to commercial media production.
6. **Harmful or Unlawful Content:** Upload defamatory, obscene, harassing, fraudulent, or illegal material under Indian law (including the Information Technology Act, 2000 and Indian Penal Code / Bharatiya Nyaya Sanhita).

---

## 3. Fair Use & Media Storage Guidelines

Setsuzoku OS is built for creative media production workflows (video editing, CGI rendering, audio mastering, design reviews). While generous file limits are supported:
- Single deliverable file uploads must not exceed 500 MB without prior enterprise tier approval.
- Files must belong to permitted media formats (e.g. MP4, MOV, WAV, ProRes, PDF, PNG, JPG, ZIP).

---

## 4. Enforcement & Account Suspension

Setsuzoku reserves the right to investigate suspected violations of this policy. If a violation is confirmed, we may:
1. Remove or disable access to infringing or malicious content.
2. Temporarily suspend account access pending security review.
3. Terminate access for repeat or egregious offenders.
4. Report criminal behavior to appropriate law enforcement authorities (e.g. Cyber Crime Cell of Mumbai / State Police).
